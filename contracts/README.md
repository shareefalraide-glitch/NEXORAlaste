# 📘 عقود NEXORA

- `openapi.json`: العمليات المنفذة حاليًا في Go فقط، بما فيها نقطة L2 الداخلية. `x-implementation-status: implemented`؛ الاستجابة لا تعني جاهزية إنتاج.
- `planned.openapi.json`: مسودة عمليات مطلوبة أو مرشحة، ووسم كل منها `planned`. **لا توجد لها خوادم منفذة في هذا التسليم.** الحقول والأدوار والخصوصية تحتاج مراجعة الفريق قبل تثبيتها؛ بعض المقترحات تتعلق بـ1.7 ولم ترد تفاصيلها الكاملة في الملفات المتاحة.
- `ml-preview.openapi.json`: ثلاث عمليات في خدمة Python منفصلة، منها معاينة حساب غير تشغيلية لا نموذج مدرّب.
- `schemas/normalized-event.v1.schema.json`: مخطط الحدث المحدود المستوحى من ECS في الاستقبال الحالي؛ لا يدعي التوافق الشامل مع ECS.

كل العقود OpenAPI 3.1 ويمكن استيرادها في أدوات API. شغّل `python scripts/check_contracts.py` بعد تثبيت `tools/requirements-contracts.txt`. يفحص السكربت صحة الوثائق ومساواة مسارات Go المنفذة وغياب تداخل المنفذ مع المخطط، لكنه لا يثبت جميع قيود البيانات أو الأمان. `scripts/contract_smoke.py` يختبر استجابات حقيقية على قاعدة مخصصة ويحوي تحذيرات الأمان في دليل التطوير.

التواريخ يجب أن تتضمن إزاحة وتُخزن UTC مع الحفاظ على النص الأصلي. نطاق الفترة `[from,to)`؛ لا تعدّ علاقة سجلين دليلًا على سببية أو اتصال فعلي. لا تعرض المعلومات غير المتاحة كصفر. العقود المستقبلية لا تعني أن التقاطًا أو كشفًا أو تنفيذ احتواء قد حدث.
