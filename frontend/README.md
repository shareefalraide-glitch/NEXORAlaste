# 📘 واجهة NEXORA (NEXORA UI)

واجهة عربية تفاعلية لمركز العمليات الأمنية، مبنية بـ React وVite. وضع Demo هو الافتراضي ويستخدم بيانات محلية. يتوفر وضع API اختياري محدود للاتصال بخادم Go، موضح في [`../docs/FRONTEND_API_MODE.md`](../docs/FRONTEND_API_MODE.md).

## 🚀 تشغيل سريع

المتطلبات: Node.js بالإصدارات `20.19+` ضمن سلسلة 20، أو `22.13+` ضمن سلسلة 22، أو `24+`، مع npm.

<div dir="ltr">

```bash
npm ci
npm run dev
```

</div>

افتح العنوان الذي يظهر في الطرفية. للدخول التجريبي استخدم زر «استخدام بيانات تجريبية»، ثم رمز `123456`. هذه ليست مصادقة حقيقية، فلا تُدخل بيانات حساسة.

توجد نسخة مستقلة جاهزة للعرض في `demo/NEXORA_UI_Demo.html`، وتعمل دون خادم بعد تنزيلها وفتحها في متصفح حديث. قد يمنع عارض الملفات المعزول الطباعة أو التنزيل؛ افتح الملف في المتصفح عند اختبارهما.

## ✅ البناء والتحقق

<div dir="ltr">

```bash
npm run build          # ينشئ dist/index.html المستقل
npm run test:structure # مسارات الاستيراد، وحدود shared، وترتيب طبقات CSS
npm run test:unit      # اختبارات النموذج والدوال المستخرجة
npm run lint           # فحص المعرّفات وأسماء مكوّنات JSX وقواعد Hooks
npm run format:check   # التحقق من التنسيق الموحد
npm run format         # تنسيق ملفات الكود والأنماط والاختبارات
npm test               # كل ما سبق، والبناء، واختبارات الواجهة والمتصفحات
```

</div>

بعد البناء، إذا أردت تحديث نسخة العرض الموزّعة داخل المشروع:

<div dir="ltr">

```bash
cp dist/index.html demo/NEXORA_UI_Demo.html
```

</div>

قبل اختبارات المتصفحات لأول مرة ثبّت محركات Playwright الثلاثة:

<div dir="ltr">

```bash
npx playwright install chromium firefox webkit
```

</div>

قد تحتاج Linux إلى حزم نظام إضافية؛ يمكن تثبيتها بصلاحيات المدير باستخدام `npx playwright install-deps chromium firefox webkit`. فحص Orca اختياري وله متطلبات منفصلة؛ راجع `docs/ACCESSIBILITY_TESTING.md`.

## 📖 خريطة سريعة

<div dir="ltr">

```text
src/
  app/             غلاف التطبيق، التنقل، الحوارات، وإجراءات العينة
  data/fixtures/   بيانات تجريبية ثابتة
  features/        الوظائف والشاشات مقسمة حسب المجال
  shared/          مكونات وأدوات واجهة مشتركة
  styles/          الأنماط العامة وطبقاتها بترتيب ثابت
  assets/          الشعارات وأيقونة المتصفح
  main.jsx         نقطة بدء التطبيق وتحميل الأنماط

tests/             اختبارات الوحدات والواجهة والسيناريوهات والوصول
docs/              المعمارية ودليل الميزات والتوثيق والقبول
scripts/           أدوات البناء والتحقق وإنشاء المستندات
demo/              نسخة HTML المستقلة
```

</div>

تقسّم `styles/base/` الأنماط الأساسية إلى ملفات مختصة، ويضبط `src/main.jsx` ترتيبها حفاظًا على المظهر.

## ⚠️ حدود النموذج

في وضع Demo تكون البيانات خيالية ومحلية، ولا يوجد اتصال بالخادم أو مصادقة حقيقية أو رصد أو تنفيذ إجراءات أمنية. وضع API الاختياري يوفّر مصادقة وخدمات قراءة/كتابة محدودة فقط، ولا يجعل بقية الشاشات تجريبية متصلة. في Demo تُمسح حالة السجلات والمسودات عند تحديث الصفحة أو الخروج؛ قد تبقى بعض تفضيلات العرض محليًا إن سمح المتصفح. الملفات التي ينزّلها المستخدم تبقى على جهازه. الاختبارات الآلية ليست شهادة WCAG ولا تحل محل تجربة المستخدم أو فحص قارئ الشاشة البشري.

استمرار حركة الكرة والرادار دون زر إيقاف مقصود بطلب صاحب النموذج، بما في ذلك عند تفعيل تفضيل تقليل الحركة. هذا قيد يجب تقييمه قبل النشر العام.
