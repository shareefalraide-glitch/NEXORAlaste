# 📘 الوضع الأمني والحدود قبل أي نشر

**هذا الكود بيئة تطوير لا منتج أمني جاهز.** يرفض الخادم `NEXORA_ENV=production` عمدًا. لا تعرضه على الإنترنت ولا ترسل إليه بيانات حقيقية أو أدلة أو كلمات مرور إنتاجية. نتائج الاختبارات ليست تدقيقًا أمنيًا أو شهادة امتثال.

## 📖 ضوابط منفذة في الشريحة

- كلمات المرور تُجزّأ بـbcrypt بكلفة 12؛ الحد الأدنى 14 محرفًا والحد الأعلى 72 بايت UTF-8. لا توجد كلمة مرور أو سر افتراضي. يراجع التأسيس بريد المؤسسة والأدوار.
- رمز وصول JWT موقّع HS256 مدته 15 دقيقة، ورمز تحديث عشوائي opaque مخزن كـSHA-256 لمدة جلسة قصوى 7 أيام. التحديث يدوّر الرمز، وتسجيل الخروج يلغي الجلسة؛ يُراجع الخادم الجلسة ودور المستخدم في قاعدة البيانات في كل طلب محمي.
- الأدوار الأساسية منفذة لكل مسار، وهوية المؤسسة تؤخذ من الجلسة لا من معرّف يرسله العميل. القيود المركبة والاستعلامات تمنع ربط بيانات مؤسستين في التدفقات المختبرة. هذا ليس بديلًا عن RLS ومراجعة سياسات مفصّلة.
- رمز المصدر عشوائي ويُخزَّن كبصمة ويُعرض عند الإنشاء أو التدوير مرة واحدة؛ يمكن تدويره أو إلغاؤه. واجهة استقبال الأحداث محصورة برمز مصدر فعّال وتفصل المؤسسة تلقائيًا.
- عمليات الكتابة المنفذة تقرن بقيد تدقيق في المعاملة، مع ربط SHA-256 وقفل متزامن على مستوى المؤسسة ومحفزات تمنع `UPDATE` و`DELETE` و`TRUNCATE` في الوضع العادي. يتحقق المسار من أول 10,000 قيد ويصرّح إذا لم يكمل.
- التحقق من المدخلات ورفض حقول JSON غير المعروفة، واستعلامات SQL ذات معاملات، وحجم طلب محدود، وأخطاء عامة، وحد تسجيل دخول/تحديث في الذاكرة، وعدم تسجيل كلمات المرور والرموز عمدًا. الحوادث اليدوية موسومة `manual`؛ الانتقال إلى الاحتواء غير متاح.

## ⚠️ ثغرات تصميمية مفتوحة وموانع الإنتاج

1. **TLS والشبكة والأسرار:** Compose يستخدم HTTP و`sslmode=disable` ومستخدم قاعدة بيانات واسع الصلاحية؛ لا تكامل مع مخزن أسرار أو تدوير مفاتيح JWT أو شهادات خدمات. مطلوب TLS، شبكة إدارية، دور DB محدود، إدارة أسرار وفرض وضع إنتاج مدروس.
2. **الجلسات:** لا MFA أو استعادة حساب أو دعوات أو انتهاء جماعي أو تحقق موزع من محاولات الدخول. الاستجابة تعيد رمز التحديث في JSON للاختبار؛ واجهة المتصفح لم تُربط. يجب اعتماد BFF/كوكي `HttpOnly` و`Secure` وسياسة `SameSite` وCSRF وحماية إعادة استخدام الرمز قبل دمج المتصفح؛ لا تحفظ رموزًا طويلة في `localStorage`.
3. **التفويض:** الأدوار ثابتة وبسيطة؛ التفويض الدقيق لكل مورد، RLS، إبطال جلسات تغيير الدور، إدارة الصلاحيات، وتدقيق حالات الرفض لم يكتمل. يجب التحقق من صلاحيات كل endpoint مخطط بدل الاعتماد على إخفاء أزرار الواجهة.
4. **التدقيق:** السجل موجود في قاعدة التشغيل نفسها دون مخزن مستقل أو مرساة خارجية أو نسخ واستعادة مختبرة. مالك/مدير القاعدة يمكنه تعطيل المحفزات وإعادة كتابة السلسلة أو حذف ذيلها؛ عدم اكتشاف التغيير لا يثبت سلامة التاريخ. هدف الحماية المكتمل موثق في P1-04.
5. **معدل الطلبات والاستشعار:** المحدد الحالي محلي للعملية ويطبق على الدخول/التحديث فقط؛ لا حماية موزعة لكل عميل أو mTLS أو إثبات سلامة مصدر. لا يوجد فحص انحراف الوقت أو معالجة صفوف/إعادة محاولة أو إثبات إنتاجية.
6. **الأدلة والاستجابة:** لا تخزين آمن للأدلة أو فحص ملفات أو سلسلة حيازة أو موافقات فعلية أو موصل احتواء. لا توجد عملية تنفيذ فعلية، ويُرفض انتقال الحادثة إلى `contained` حتى تُبنى سلسلة الموافقة والتحقق.
7. **التحليل:** خدمة Python حساب معاينة من أرقام يزوّدها المستدعي؛ لا تتحقق من صحة خط الأساس أو وجود نموذج، ولم تُدرَّب أو تُعايَر أو تُربط بخدمة الأعمال. لا تستخدم درجتها لاتخاذ قرار أمني.
8. **العمليات والصور:** لا اختبارات تحمل أو استعادة أو pentest أو فحص بشري أو شهادة WCAG. صور Compose تعتمد tags قابلة للتغير وغير مثبتة ببصمات، ولم تُفحص صورها أمنيًا؛ يلزم تثبيت digest، وفحص صور واعتماد SBOM. سياسة الاحتفاظ، الحذف، التشفير عند التخزين، فحص الملفات، كشف التلاعب ذي المراسي، السجلات الموزعة والنسخ الاحتياطي مهام مفتوحة.

## 📖 التبعيات

في اختبار 3 نوفمبر 2026 لم يُظهر `npm audit` للواجهة أو `pip-audit` لاعتمادات Python التشغيلية والتطويرية ثغرات معروفة. استُخدم override إلى `minimatch` 11.0.4 لمعالجة تحذير تطوير في ESLint؛ الاختبارات والبناء نجحا، لكن يجب مراجعة هذا التجاوز عند تحديث ESLint لأنه يفرض إصدارًا رئيسيًا خارج نطاقه المعلن. فحص `govulncheck` للثنائي لم يجد رمزًا مستدعى متأثرًا، لكنه أظهر تنبيهًا على حزمة `openpgp` القديمة داخل وحدة `golang.org/x/crypto` غير المستخدمة هنا. فحص المصدر الكامل لم يكتمل بسبب ذاكرة البيئة، وأُضيف إلى CI لإعادته في بيئة مناسبة ومتابعة التنبيه والتحديثات. هذه نتائج مؤقتة لا تثبت خلو التبعيات أو المنتج من المخاطر.
