# استيراد ملفات Suricata وZeek (محول محلي)

يوفر `tools/import_sensor_logs.py` محولًا حقيقيًا يعمل دون اعتماديات خارجية لملفات **محلية** بصيغ Suricata EVE JSON Lines وZeek JSON Lines وZeek TSV. هذا ليس جامعًا مستمرًا، ولا يراقب الشبكة، ولا يشغّل قواعد كشف. الإخراج أحداث مطبّعة متوافقة مع الجزء المحدود من عقد NEXORA الحالي؛ لا يضيف المحول كشفًا أو تنبيهات.

## الحدود والتحقق

- حتى 900,000 بايت و100 سجل لكل ملف/دفعة. يعالج الملف كاملًا ويرفضه عند أي سجل غير صالح بدل تخطيه بصمت.
- يرفض UTF-8 غير الصالح، JSON غير الصحيح، الحقول المطلوبة الناقصة، الوقت بلا منطقة زمنية، IP غير صحيح، والرسائل التي تتجاوز 4,096 حرفًا.
- يحول الأوقات إلى UTC بصيغة RFC3339، بما في ذلك أزمنة Zeek العددية، ويستخرج عنواني المصدر والوجهة وملخصًا نصيًا متاحًا.
- `source_sequence` ثابت مشتق من رقم السطر ومحتواه؛ إعادة استيراد الملف نفسه تساعد على منع التكرار ضمن قيد قاعدة البيانات. تعديل الملف أو ترتيب أسطره ينتج تسلسلات مختلفة.
- يرفض الحقول الخام غير المدعومة بدل الادعاء بتطبيع ECS كامل. لا يستورد محتوى الحزم أو مرفقات.
- الاستيراد يعتمد على `POST /internal/v1/event-batches` ورمز مصدر صالح. الإنشاء الآمن وإلغاء/تدوير الرمز موضح في `docs/DEVELOPMENT.md`. لا تخزن الرمز في الملف أو سجل الأوامر.

## التشغيل

من جذر المستودع، باستخدام Python 3.10+ دون تثبيت حزم:

<div dir="ltr">

```bash
python tools/import_sensor_logs.py suricata-eve docs/examples/suricata-eve.synthetic.jsonl > batch.json
python tools/import_sensor_logs.py zeek-json /path/to/conn.log > batch.json
python tools/import_sensor_logs.py zeek-tsv /path/to/conn.log -o batch.json
```

</div>

راجع محتوى الملف الناتج وتأكد من المصدر والتوقيت قبل إرساله. بعد إعداد خدمة Go محليًا، أرسل الدفعة عبر HTTPS في بيئة مناسبة أو localhost في التطوير:

<div dir="ltr">

```bash
curl --fail-with-body -X POST http://127.0.0.1:8080/internal/v1/event-batches \
  -H 'Content-Type: application/json' \
  -H "X-Source-Token: ${NEXORA_SOURCE_TOKEN}" \
  --data-binary @batch.json
```

</div>

هذه الخطوة تختبر استقبال API الفعلي فقط إذا كان الخادم وقاعدة البيانات ورمز المصدر جاهزين. مخرجات المحول وحدها لا تثبت نجاح التخزين. عملية الإدخال محمية بمعاملة، ويعيد API عدادي المقبول والمكرر؛ لا توجد قواعد كشف أو إنشاء تنبيهات مرتبطة بها حاليًا.

الملف `docs/examples/suricata-eve.synthetic.jsonl` بيانات اصطناعية موثقة ومخصصة للاختبار، لا تمثل حركة فعلية. شغّل:

<div dir="ltr">

```bash
python -m unittest tools.test_import_sensor_logs -v
```

</div>
