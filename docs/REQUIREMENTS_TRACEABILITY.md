## 🔐 الأمن SR-01–SR-08

| المتطلب | الحالة |
|---|---|
| SR-01 | **جزئي:** تجزئة مكلفة وJWT وتحديث وتحقق جلسة في الـBackend؛ لا MFA أو دمج آمن للمتصفح. P1-01. |
| SR-02 | **جزئي:** RBAC وعزل في العمليات المنفذة؛ لا سياسات موارد شاملة ولا RLS. P1-02. |
| SR-03 | غير منفذ: لا TLS في Compose المحلي. P1-03. |
| SR-04 | **جزئي:** استعلامات معلمات ومدخلات محدودة؛ تطهير كل السجلات المستوردة عند العرض غير منفذ. P2-02/P5-01. |
| SR-05 | **جزئي:** hash-chain ومحفزات وتحقق داخل نفس القاعدة؛ لا مخزن مستقل أو مرساة تمنع حذف الذيل. P1-04. |
| SR-06 | غير منفذ: لا مستشعر حقيقي أو سياسة حمايته. P2-01/06. |
| SR-07 | **جزئي:** منافذ التطوير على loopback والحاويات مقيدة؛ ليست مراجعة هجوم أو نشر. P1-03. |
| SR-08 | **جزئي:** أسرار البيئة مستثناة من Git؛ لا مدير أسرار أو TLS أو تدوير JWT. P1-03. |

## 🚀 متطلبات الأداء والتشغيل NFR

لا توجد قياسات قبول للأهداف NFR-01 إلى NFR-09، بما فيها 2000 حدث/ثانية، <5 ثوانٍ للفهرسة، <30 ثانية للحادثة، 50 غ.ب/يوم، واستهلاك الموارد والتوافر. لا نموذج أو خط التقاط كامل لقياسه. دعم العربية والاتجاه في الواجهة تجريبي (NFR-10) مع حاجة إلى اختبار بشري، وحركة الكرة والرادار قرار قائم لصاحب المنتج. توجد خدمات وعقود منفصلة كأساس NFR-11، ونجح تشغيل **الشريحة الحالية فقط** داخل Compose لـNFR-12، وليس نشر جميع وظائف التقرير من بيئة نظيفة أو قبول قابلية النقل للمنتج الكامل.
