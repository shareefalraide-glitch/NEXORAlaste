# 📘 تقرير التحقق وحدوده

تاريخ التحقق: 3 نوفمبر 2026. الاختبارات المذكورة تخص الشريحة الموجودة في هذا التسليم، لا المتطلبات المستقبلية أو سلامة منصة إنتاجية.

## 📖 Backend وPostgreSQL

- اختُبرت خدمة Go 1.27.3 على PostgreSQL 16.15 (وكذلك مجموعة أقدم على 17) باستخدام `go test -race -v ./...` و`go vet ./...`. شملت اختبارات قاعدة حقيقية عزل المؤسسات، الصلاحيات، تدوير الجلسات ورمز المصدر، الأحداث المتكررة، رفض عكس ارتباط أصل من مؤسسة أخرى، المهام والتحولات المحظورة، إعادة تنفيذ الهجرات، رفض تغيير بصمتها، معاملة التدقيق والتلاعب و20 كتابة متزامنة.
- تحقق `scripts/check_contracts.py` من مستندات OpenAPI، وقائمة مسارات Go، وعدم تداخل المنفذ مع المخطط، وتطابق مخطط الحدث الفرعي. النتيجة: 32 عملية Go منفذة، 100 مسودة، 3 عمليات لخدمة معاينة Python. هذا فحص بنيوي ولا يثبت كل تفاصيل الأمان أو جميع الحالات.
- اختبر `scripts/contract_smoke.py` عمليات Go الـ32 عبر HTTP حقيقي بمطابقة مخططات استجابات النجاح في OpenAPI، إلى جانب حالات رفض مختارة. لا يغطي كل تركيبات الإدخال أو الحدود أو حالات التزامن ولا العمليات المستقبلية.

## 📖 Docker Compose

- بُنيت صورتا Go وPython وشُغّل PostgreSQL 16 بالحاويات محليًا على Linux باستخدام Docker 26.1.5 وCompose 2.26.1. أُنشئت قاعدة اختبار، ونُفذت الهجرات والتأسيس، ونشطت الخدمة على منفذ loopback، ثم نجح اختبار HTTP ومخططات الاستجابات لكل عمليات Go الـ32.
- شُغلت حاوية معاينة Python دون منفذ منشور للمضيف؛ تحقق HTTP من الجاهزية ورفض غياب الرمز والاستجابة غير التشغيلية وقيمة `0.20` المنخفضة ورفض درجة نصية غير صالحة. لا يتصل Go بـPython.
- أُعيدت التجربة من استخراج نظيف لأرشيف المشروع مع وحدة تخزين PostgreSQL جديدة؛ نجح البناء والتأسيس واختبار العمليات الـ32 بعد انتظار جاهزية الخدمة. نجحت أيضًا في الاستخراج نفسه اختبارات Go مع `-race` و`go vet`، وإنشاء بيئة Python جديدة و6 اختبارات، وتثبيت npm والبناء وفحوص الوحدات والتنسيق و`lint`.
- هذه تجربة محلية لشريحة المشروع فقط، وليست اختبار نقل لكل نظام تشغيل أو فحص صور حاويات أو تشغيلًا آمنًا في الإنتاج. بيانات التجربة عابرة وقابلة للحذف.

## 📖 Python

- نجحت 6 اختبارات `pytest`، بما فيها جرد المسارات ومطابقة مخططات الاستجابات المختارة، ورفض الإدخال والمعرّف أو التأسيس غير الصالحين، ودقة معادلة المعاينة. لا نموذج مدرّب أو تقييم جودة كشف أو تحقق ميداني من خط الأساس.
- `pip-audit` لاعتمادات التشغيل والتطوير المقفلة لم يجد ثغرات معروفة وقت الفحص. فحص `gitleaks` v8.30.1 لنسخة ملفات المشروع النظيفة لم يجد أسرارًا مطابقة لقواعده؛ لا يضمن ذلك اكتشاف كل سر أو فحص محتوى المستندات الثنائية.

## 📖 الواجهة

- نجحت `npm ci`، وفحص البنية والوحدات، و`lint` و`format:check` والبناء. نتج HTML مستقل مطابق بايتًا لنسخة الواجهة السابقة؛ تم تحديث تبعية تطوير عبر override بعد فحص التبعيات دون تغيير ناتج الواجهة.

- `npm audit` للاعتمادات التشغيلية والتطويرية لم يجد ثغرات معروفة وقت الفحص. الاختبارات الكاملة الأقدم للواجهة موثقة في `frontend/docs/RESTRUCTURE_REPORT.md`، ولا يلزم أنها أُعيدت كلها لهذا التسليم.
