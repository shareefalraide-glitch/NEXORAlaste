# 🎯 مهمة رقم: P3-01

**العنوان:** كشف القواعد التوقيعية  
**القسم:** الكشف والذكاء الاصطناعي — المسار P3  
**الأولوية:** 🔴 عالية (P0)  
**المسؤول المقترح:** P3 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-05, FR-17  
**الاعتماديات:** P2-02  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

طبّق Sigma على الأحداث الموحّدة وSuricata على الحزم عبر صيغه الأصلية؛ افصل المسارين ولا تحوّل Sigma إلى قاعدة حزم.

## ✅ خطوات التنفيذ

1. حدد صيغ عينات القواعد وبيانات الاختبار الموسومة لكل مسار كشف.
2. نفّذ تطبيق Sigma على الأحداث الموحّدة وSuricata الأصلية على الحزم كمسارين منفصلين.
3. اختبر المطابقة وعدمها وإصدار القواعد ومراجعتها قبل التفعيل مع إظهار المنشأ.

### ✅ معايير القبول

- [ ] اختبار مطابقة وعدم مطابقة على سجلات موسومة وتاريخية، إصدار قاعدة ومراجعتها قبل تفعيلها، مع بيان مصدر النتيجة.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- خلط قواعد الأحداث مع قواعد الحزم: احتفظ بتفسير وتنفيذ منفصل لكل صيغة.
- الإنذارات الكاذبة أو قاعدة غير مراجعة: اختبر على عينات تاريخية وراجع النتيجة قبل التفعيل.

## 📌 ملاحظات إضافية

- تُراجع المهمة ويُتفق على تفاصيل العقد قبل التنفيذ، ولا تتحول إلى حالة «منفذة» دون كود واختبارات.
