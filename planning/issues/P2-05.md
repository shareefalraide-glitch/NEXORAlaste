# 🎯 مهمة رقم: P2-05

**العنوان:** Timescale والاحتفاظ والاستعلام عالي الحجم  
**القسم:** الاستشعار والبيانات والتطبيع — المسار P2  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P2 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-04, NFR-01, NFR-04  
**الاعتماديات:** P2-02  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

صمّم تخزين PostgreSQL 16 مع Timescale وفهارس وترقيم cursor وأرشفة ساخنة/باردة؛ أبقِ ClickHouse للتوسع عند الحاجة.

## ✅ خطوات التنفيذ

1. صمّم مخطط Timescale والفهارس وترقيم النتائج وطبقتي الاحتفاظ اعتمادًا على نموذج الأحداث.
2. أضف هجرة واختبارات إدخال واستعلام واحتفاظ واستعادة لبيئة تطوير معزولة.
3. قِس الحمل والزمن والحجم والفقد، ووثّق النتائج مقارنةً بالهدف دون افتراض تحققه.

### ✅ معايير القبول

- [ ] هجرة واختبار استعادة واحتفاظ؛ قياس 2000 حدث/ثانية، زمن الفهرسة، حجم البيانات والفقد على بيئة معلنة.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- تدهور الأداء مع نمو حجم الأحداث: اختبر الفهارس والاستعلامات على حمل معلن وممثل.
- حذف بيانات قبل موعدها أو تعذر استعادتها: راجع سياسة الاحتفاظ واختبر الاستعادة دوريًا.
