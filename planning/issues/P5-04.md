# 🎯 مهمة رقم: P5-04

**العنوان:** التقارير والتصدير الانتقائي  
**القسم:** الواجهة وتجربة المحلل والجودة — المسار P5  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P5 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-19, FR-24  
**الاعتماديات:** P4-04, P4-05  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

اربط مصمم التقرير والتصدير الآمن والخادم، مع اختيار الأقسام والحقول والمنشأ ومعاينة مطابقة للناتج.

## ✅ خطوات التنفيذ

1. اتفق على حقول التقرير الاختيارية والمنشأ وحقوق الوصول ومدة الإتاحة.
2. أنشئ المعاينة والتصدير الانتقائي مع معالجة CSV واستبعاد الصور افتراضيًا.
3. قارن الملف بالمعاينة واختبر صلاحيات التنزيل وانتهاء الرابط ومخاطر البيانات.

### ✅ معايير القبول

- [ ] اختبار تطابق المعاينة والملف، ومعالجة حقن CSV، واستبعاد الصور افتراضيًا، وحقوق الوصول وانتهاء صلاحية الملف.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- تسرّب قسم أو صورة لم يطلبها المستخدم: أظهر الاختيار وراجع المحتوى النهائي.
- حقن صيغ CSV أو وصول غير مخول: عالج القيم وافحص الصلاحية والتوقيت.
