# 🎯 مهمة رقم: P3-06

**العنوان:** مؤشرات التهديد وتغطية MITRE  
**القسم:** الكشف والذكاء الاصطناعي — المسار P3  
**الأولوية:** 🟢 منخفضة (P2)  
**المسؤول المقترح:** P3 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-18, FR-23  
**الاعتماديات:** P3-01, P2-04  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

استورد حزم IoC محلية واعرض تغطية ربط القواعد بتقنيات MITRE مع مصدر وإصدار وتاريخ.

## ✅ خطوات التنفيذ

1. حدّد صيغة الحزمة المحلية ومصدرها وإصدار المؤشرات وتاريخ انتهاء الصلاحية.
2. صمّم الاستيراد الآمن وربط القواعد المراجَعة بتقنيات MITRE على نحو قابل للتدقيق.
3. اختبر الحزم غير الصالحة والمؤشرات المنتهية ووضوح حدود التغطية.

### ✅ معايير القبول

- [ ] اختبار صلاحية الحزمة وانتهاء المؤشر؛ الربط لا يدعي فعالية قاعدة غير مختبرة ولا اتصالًا خارجيًا غير منفذ.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- مؤشرات قديمة أو مجهولة المصدر: تحقق من الإصدار والصلاحية واحتفظ بالمنشأ.
- الإيحاء بفعالية كشف غير مثبتة: ميّز الربط التصنيفي عن أداء قاعدة مجرَّب.
