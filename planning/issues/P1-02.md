# 🎯 مهمة رقم: P1-02

**العنوان:** سياسة تفويض وعزل المؤسسات  
**القسم:** أمن المنصة والهوية والتشغيل — المسار P1  
**الأولوية:** 🔴 عالية (P0)  
**المسؤول المقترح:** P1 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-15, SR-02  
**الاعتماديات:** P1-01  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

حوّل مصفوفة الصلاحيات إلى سياسات مورد وعملية على الخادم؛ اختبر حدود المؤسسة في جميع الموارد والعلاقات.

## ✅ خطوات التنفيذ

1. وثّق مصفوفة الأدوار والموارد والعمليات، وحدد هوية المؤسسة من جلسة الخادم.
2. طبّق التحقق لكل قراءة وكتابة وعلاقة، مع مراجعة القيود على مستوى قاعدة البيانات.
3. اختبر كل دور بمؤسستين وموارد مترابطة، ثم وثّق الحالات المسموحة والمرفوضة.

### ✅ معايير القبول

- [ ] اختبارات سلبية لكل دور ولكل مورد؛ لا تمر أي قراءة أو كتابة بمعرّف مؤسسة أخرى؛ المراجعة موثقة مع الفريق.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- تسرّب مورد عبر علاقة متقاطعة: استخدم استعلامات مقيدة بالمؤسسة ومفاتيح مترابطة واختبر المعرفات الأجنبية.
- الاعتماد على إخفاء الأزرار: اجعل الخادم يفحص الصلاحية في كل مسار حتى عند طلبه مباشرة.
