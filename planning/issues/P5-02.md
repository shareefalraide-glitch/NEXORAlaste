# 🎯 مهمة رقم: P5-02

**العنوان:** لوحة بمؤشرات حقيقية ومنشأ  
**القسم:** الواجهة وتجربة المحلل والجودة — المسار P5  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P5 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-13, FR-14  
**الاعتماديات:** P3-05, P4-01, P5-01  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

اربط المقاييس بالفترة ومصدرها وحداثتها، وافصل لقطات الأصول عن عدادات الأحداث والتنبيهات.

## ✅ خطوات التنفيذ

1. حدد تعريف كل مؤشر وفترته ومصدره وتاريخ آخر تحديث.
2. اربط المقاييس المنفذة وميّز الأرقام الحالية عن القيم غير المتاحة.
3. اختبر الفترات والمظهرين والشاشات، وحافظ على حركة الكرة والرادار المطلوبة.

### ✅ معايير القبول

- [ ] غير المتوفر يظهر غير متاح لا صفرًا؛ اختبار زمن ومقاسات وثيمين، مع عدم تغيير الكرة والرادار المطلوبين.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- تحويل نقص بيانات الكشف إلى صفر مضلل: اعرض غير متاح مع تفسير المصدر.
- اختلاف معنى لقطة الأصل عن عدد الأحداث: وثّق نوع المؤشر وفترته ولا تجمعهما.
