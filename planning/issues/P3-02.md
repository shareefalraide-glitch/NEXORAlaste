# 🎯 مهمة رقم: P3-02

**العنوان:** السمات الاثنتا عشرة وخط الأساس  
**القسم:** الكشف والذكاء الاصطناعي — المسار P3  
**الأولوية:** 🔴 عالية (P0)  
**المسؤول المقترح:** P3 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-25, FR-26  
**الاعتماديات:** P2-02  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

استخرج السمات الاثنتي عشرة من الملحق ب وحوّلها ووحّدها، مع خط أساس لكل أصل وبدء 14 يومًا أو 100000 حدث أيهما أولًا.

## ✅ خطوات التنفيذ

1. راجع السمات الاثنتي عشرة وتحويلاتها في ملحق التقرير ومصادر البيانات المطلوبة.
2. نفّذ استخراج السمات وتحويلها وخط أساس منفصل لكل أصل وفق الحد المعلن.
3. قارن الحساب بعينات يدوية واختبر القيم المفقودة والبدء البارد وانحراف الوقت.

### ✅ معايير القبول

- [ ] كل قيمة مطابقة لعينة حساب يدوية؛ منع إصدار درجة قبل التأسيس؛ معالجة القيم الناقصة وانحراف الوقت دون اختلاق صفر.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- إصدار درجة قبل اكتمال خط الأساس: امنع النتيجة التشغيلية حتى استيفاء الشرط.
- قيم مفقودة أو توقيت غير موثوق: أظهر نقص البيانات ولا تستبدله بصفر مفترض.
