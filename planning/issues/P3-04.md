# 🎯 مهمة رقم: P3-04

**العنوان:** حوكمة العتبة والنموذج والتراجع  
**القسم:** الكشف والذكاء الاصطناعي — المسار P3  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P3 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-27, FR-28, FR-12  
**الاعتماديات:** P3-03, P1-04  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

نفّذ معايرة مؤرخة ومنحنى دقة/استدعاء، اعتمادًا بشريًا، مراقبة الانحراف، تحديثًا محدودًا وتراجعًا للنسخة المعتمدة.

## ✅ خطوات التنفيذ

1. حدد مجموعة التحقق الزمني ومعايير اعتماد النموذج وسياسة تسجيل العتبة.
2. أضف معايرة موثقة ومراقبة انحراف واعتمادًا بشريًا وخطة تراجع لإصدار سابق.
3. اختبر فشل التقييم والانحراف ونشر نسخة غير معتمدة واسترجاع النسخة الصالحة.

### ✅ معايير القبول

- [ ] رفض نشر نموذج غير مقيم أو غير معتمد؛ اختبار الانحراف والتراجع وسجل قابل للتدقيق للنسخ والحدود.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- ضبط العتبة على بيانات الاختبار: افصل التحقق الزمني عن مجموعة الحجز النهائية.
- تعذر استرجاع نموذج سابق: احتفظ بالنسخة والإعدادات المعتمدة واختبر التراجع.
