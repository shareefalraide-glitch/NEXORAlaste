# 🎯 مهمة رقم: P4-05

**العنوان:** دفتر التحقيق والمهام والروابط  
**القسم:** إدارة الحوادث والاستجابة — المسار P4  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P4 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-10, FR-19  
**الاعتماديات:** P4-02, P4-04  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

أكمل دفتر الحادثة والروابط والمسودات والقوالب المقترحة مع فصل حالة كل محقق ومعرّفات ثابتة.

## ✅ خطوات التنفيذ

1. حدد نموذج الدفتر والمهام والروابط والمسودات والمعرّفات المستقرة لكل محقق.
2. نفّذ الحفظ والعزل وربط المراجع مع معالجة تعارض التعديل والتصدير المحدد.
3. اختبر صلاحيات المستخدمين والمؤسسات ومطابقة المراجع وعدم تحويل الاقتران إلى سبب.

### ✅ معايير القبول

- [ ] حفظ وعزل البيانات والمراجع؛ لا يُحوّل الاقتران إلى سبب؛ اختبار تعارض التحرير والصلاحية والتصدير المحدد.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- تداخل مسودات المحققين: افصل سياق كل محقق واختبر تغيير التحقيق والتعارض.
- استنتاج علاقة من مجرد اقتران: احتفظ بالأدلة والمصدر واعرض حدود الاستنتاج.
