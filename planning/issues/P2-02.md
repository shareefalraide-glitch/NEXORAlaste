# 🎯 مهمة رقم: P2-02

**العنوان:** مخطط أحداث موحد وقابلية الإعادة  
**القسم:** الاستشعار والبيانات والتطبيع — المسار P2  
**الأولوية:** 🔴 عالية (P0)  
**المسؤول المقترح:** P2 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-02, FR-04  
**الاعتماديات:** P2-01  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

راجع تقارب ECS وحقول المصدر والطابع الأصلي وUTC ومفتاح المصدر/الزمن/التسلسل؛ نفّذ سياسة تطور المخطط.

## ✅ خطوات التنفيذ

1. راجع الحقول المعتمدة ومطابقتها الجزئية لـECS، مع حفظ الطابع الأصلي وUTC.
2. حدّد المفتاح الطبيعي وإصدارات المخطط وسياسة التعامل مع القيم المفقودة والتكرار.
3. اختبر المخطط والمدخلات الخاطئة وإعادة إرسال الدفعات مع الحفاظ على مصدر السجل.

### ✅ معايير القبول

- [ ] عقد بيانات واختبارات وحدات ورفض حقول خاطئة وتكرار آمن؛ لا يعرض التكرار كسجل جديد ولا يفقد الأصل.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- تكرار الرسائل بعد إعادة الإرسال: استخدم مفتاحًا مستقرًا واختبارات إعادة آمنة.
- فقد المصدر أو معنى الحقل أثناء التطبيع: احتفظ بالمنشأ والطابع الأصلي ووثّق التحويلات.
