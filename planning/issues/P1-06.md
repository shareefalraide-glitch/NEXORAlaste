# 🎯 مهمة رقم: P1-06

**العنوان:** النسخ والاستعادة وسياسات الاحتفاظ  
**القسم:** أمن المنصة والهوية والتشغيل — المسار P1  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P1 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-22, NFR-04, NFR-08  
**الاعتماديات:** P1-04, P2-05  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

صمّم سياسة احتفاظ الأحداث مقابل التشغيل والتدقيق، ونسخ قاعدة التشغيل وتجربة استعادة مع RPO/RTO كأهداف.

## ✅ خطوات التنفيذ

1. اتفق على سياسات احتفاظ الأحداث والتشغيل والتدقيق وأهداف الاستعادة.
2. نفّذ نسخًا محمية وحذفًا مجدولًا لا يزيل قيد التدقيق اللازم.
3. استعد نسخة في بيئة معزولة وقِس RPO وRTO ووثّق النتائج والفجوات.

### ✅ معايير القبول

- [ ] يُحذف المنتهي دون حذف أثره التدقيقي؛ تجربة استعادة معزولة موثّقة وقياس RPO/RTO، ولا وسم نسخة بأنها متحققة قبل الاستعادة.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- حذف أثر تدقيقي عند انتهاء حدث: افصل سياسة الحدث عن سياسة السجل وتحقق بالاختبارات.
- وجود نسخة لا يمكن استعادتها: لا تعتمد النسخ حتى تنجح تجربة استعادة موثقة.

## 📌 ملاحظات إضافية

- تُراجع المهمة ويُتفق على تفاصيل العقد قبل التنفيذ، ولا تتحول إلى حالة «منفذة» دون كود واختبارات.
