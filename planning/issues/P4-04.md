# 🎯 مهمة رقم: P4-04

**العنوان:** الأدلة وسلسلة الحيازة  
**القسم:** إدارة الحوادث والاستجابة — المسار P4  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P4 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-12, SR-02  
**الاعتماديات:** P1-04  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

صمّم رفعًا آمنًا مع SHA-256 محسوب على الخادم وتخزين محمي ومراجعة النوع والحجم، وتسجيل كل وصول ونقل وتصدير.

## ✅ خطوات التنفيذ

1. حدد أنواع الأدلة وأحجامها ومدة الاحتفاظ وحدود الوصول والتخزين.
2. نفّذ الرفع الآمن وبصمة SHA-256 على الخادم وسجل الحيازة والوصول والتصدير.
3. اختبر تغيير المحتوى وانقطاع السلسلة والوصول غير المصرح به والحذف والاستعادة.

### ✅ معايير القبول

- [ ] كشف تغيير المحتوى وانقطاع السلسلة؛ منع وصول دور غير مخول؛ اختبار مدة PCAP وحذفه وسياسة الخصوصية والاستعادة.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- العبث بالدليل أو سلسلة الحيازة: تحقق من البصمة واحتفظ بأثر مستقل لكل نقل ووصول.
- تسرب ملفات حساسة: فرض الصلاحيات وتقييد الأنواع والحجم والتشفير وفق التصميم المعتمد.
