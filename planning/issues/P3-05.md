# 🎯 مهمة رقم: P3-05

**العنوان:** دمج الدرجات وشرح المنشأ  
**القسم:** الكشف والذكاء الاصطناعي — المسار P3  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P3 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-07, FR-29  
**الاعتماديات:** P3-01, P3-03  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

طبّق الدمج وأوزانه المقترحة القابلة للمعايرة في خدمة L3، مع تفسير المكونات وإصدار مخرجات كشف موثقة إلى L4.

## ✅ خطوات التنفيذ

1. وثّق مكونات درجة الخطورة ومصادرها وأوزانها المقترحة وحالة المعايرة.
2. طبّق الدمج في خدمة الكشف بعد توافر مصادر فعلية، مع إظهار مساهمة كل مكوّن.
3. اختبر القيم الناقصة وحالات المصدر الواحد والحرجة، ثم وثّق مخرجات L3 إلى L4.

### ✅ معايير القبول

- [ ] أصل حرج وتكرار بلا قاعدة/شذوذ يبقى منخفضًا؛ حرجة تتطلب إشارتين؛ القيم الغائبة لا يُعاد توزيع وزنها، والأوزان غير المعايرة معلنة.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- استخدام درجة مدخلة يدويًا كدليل كشف: ارفض تشغيلها كإشارة ما لم تُثبت مصادرها الفعلية.
- تضخيم الخطورة عند نقص مكوّن: لا تعِد توزيع الأوزان تلقائيًا، ووضح غياب المصدر.
