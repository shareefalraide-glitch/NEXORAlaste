# 🎯 مهمة رقم: P2-01

**العنوان:** موصل استشعار سلبي وتطبيع Vector  
**القسم:** الاستشعار والبيانات والتطبيع — المسار P2  
**الأولوية:** 🔴 عالية (P0)  
**المسؤول المقترح:** P2 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-01, FR-02  
**الاعتماديات:** P1-03  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

ابدأ بمستشعر واحد Zeek أو Suricata وموصل Vector يحوّل السجلات إلى العقد المتفق عليه دون التقاط أوامر فعلية من الواجهة.

## ✅ خطوات التنفيذ

1. اختر مستشعرًا سلبيًا واحدًا وحدد عينات سجلاته وطريقة جمعه دون تعريض واجهة إدارة.
2. اضبط Vector لتحويل العينة إلى عقد الحدث الموحّد وتمريرها لمسار الاستقبال المعزول.
3. اختبر السجلات الصالحة والتالفة وتوثيق الجهاز الفعلي ومصدر كل حدث.

### ✅ معايير القبول

- [ ] عينات Zeek أو EVE تمر عبر مسار معزول؛ فشل السجلات غير الصالحة واضح؛ لا تؤدي عملية الجهاز إلى تقديم الأداة نفسها كمصدر.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- الخلط بين أداة التحليل ومصدر البيانات: عرّف الجهاز أو الباعث مصدرًا، وسجّل الأداة كطريقة جمع.
- تباين السجلات أو فشل التحويل: احتفظ بعينات آمنة واختبر الرفض وتوثيق سبب الخطأ.
