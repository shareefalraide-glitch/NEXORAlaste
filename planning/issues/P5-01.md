# 🎯 مهمة رقم: P5-01

**العنوان:** ربط React بالعقد وإدارة الحالات  
**القسم:** الواجهة وتجربة المحلل والجودة — المسار P5  
**الأولوية:** 🔴 عالية (P0)  
**المسؤول المقترح:** P5 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-13–16, SR-01  
**الاعتماديات:** P1-01, P2-02  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

أنشئ عميلًا مبنيًا على العقد وأدر التحميل والخطأ والفراغ والصلاحية مع فصل وضع العرض التجريبي.

## ✅ خطوات التنفيذ

1. راجع عقد العمليات المنفذة وحدّد نموذج جلسة متصفح آمن مع فريق الأمن.
2. ابنِ عميل API مع حالات التحميل والخطأ والفراغ والرفض وفصل وضع العرض التجريبي.
3. اربط الشاشات المتاحة تدريجيًا واختبر مؤسستين وأدوارًا وانقطاع الخدمة.

### ✅ معايير القبول

- [ ] لا تخزن رموزًا طويلة في localStorage؛ لا تستخدم بيانات نموذجية إذا فشلت API دون توضيح؛ اختبارات E2E لحسابين ومؤسستين.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- عرض عينة عند فشل الاتصال كأنها بيانات حية: اظهر وضع العرض والخطأ بوضوح.
- تخزين رموز طويلة في المتصفح: اعتمد تصميم الجلسة الآمن وCSRF بالتنسيق مع P1.
