# 🎯 مهمة رقم: P3-03

**العنوان:** تدريب Isolation Forest وتقييم معزول  
**القسم:** الكشف والذكاء الاصطناعي — المسار P3  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P3 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-06, FR-25–27  
**الاعتماديات:** P3-02  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

ابنِ نموذج CPU باستخدام scikit-learn وخزن بيانات التدريب والمصدر والإصدار؛ افصل التدريب والتحقق والاختبار زمنيًا.

## ✅ خطوات التنفيذ

1. حدد بيانات التدريب ومصدرها وإصدارات السمات مع فصل زمني للتدريب والتحقق والاختبار.
2. درّب Isolation Forest على CPU واحفظ إصدار النموذج وإعداداته وسياق البيانات.
3. قيّم على مجموعة حجز مستقلة مع تجارب قابلة لإعادة التشغيل ومقاييس وحدود ثقة.

### ✅ معايير القبول

- [ ] لا ينتج النظام درجة تشغيلية من نموذج غير مدرب؛ توجد مجموعة حجز مستقلة ومقاييس وحدود ثقة وتجارب متكررة قابلة لإعادة التشغيل.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- تسرب بيانات الاختبار إلى التدريب: اعتمد فصلًا زمنيًا وتحقق من السجلات والحدود.
- عرض قيمة معاينة كنموذج حقيقي: ارفض الدرجات التشغيلية حتى التدريب والتقييم الفعليين.
