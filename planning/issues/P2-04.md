# 🎯 مهمة رقم: P2-04

**العنوان:** جرد الأصول والواجهات والإثراء  
**القسم:** الاستشعار والبيانات والتطبيع — المسار P2  
**الأولوية:** 🟡 متوسطة (P1)  
**المسؤول المقترح:** P2 (يُربط باسم عضو الفريق بعد اختيار الأسماء).  
**المتطلبات المرتبطة:** FR-03, FR-16  
**الاعتماديات:** P1-02, P2-02  
**الحالة:** مهمة مقترحة؛ ليست وظيفة مكتملة.

## 📝 وصف المهمة

أكمل واجهات الأصل وتغيير الأهمية والربط بالمعرّف الثابت وإثراء الهوية والجغرافيا ومؤشرات التهديد ذات المصدر.

## ✅ خطوات التنفيذ

1. حدّد هوية الأصل المستقرة وبيانات واجهاته ومصادر الإثراء المسموح بها.
2. استكمل عمليات الجرد وتغيير الأهمية، ثم اربط الإثراء بالمصدر وتاريخ الصلاحية.
3. اختبر الأسماء المتكررة والهوية المجهولة وعزل المؤسسة والحقول غير المتاحة.

### ✅ معايير القبول

- [ ] تظل IP/MAC قرائن لا هوية مؤكدة؛ لا يُختار أصل بالاسم المتكرر؛ البيانات غير المتاحة لا تصبح صفرًا أو حقيقة.
- [ ] تحديث عقد API ونموذج البيانات والتوثيق عند الحاجة، مع التصريح بما لم ينفّذ.
- [ ] اختبارات وحدة وتكامل للحالات الصحيحة والسلبية، ومراجعة الأمن والخصوصية وعزل المؤسسة بحسب نطاق المهمة.
- [ ] مراجعة شخص آخر من الفريق لطلب الدمج وإرفاق دليل التحقق.

## 🛑 التحديات المتوقعة

- اعتبار IP أو MAC هوية مؤكدة: اعرضها كقرائن مرتبطة بمعرّف ثابت ومصدر.
- فقد سياق الإثراء أو غيابه: اذكر المنشأ والتوقيت، واعرض المجهول بدل اختلاق قيمة.
